# ENADE 2023 — Medicina, gabarito MD18

Fixture hermética do parser de gabaritos: contém somente o PDF original de uma página, o gold de 25 chaves conferidas visualmente e a licença depositada pelo Inep. Não inclui prova, enunciados ou figuras.

Fonte: [repositório oficial do Inep](https://riep.inep.gov.br/items/beefb951-2d91-4fc3-9f07-486da129d666/full). [PDF do gabarito](https://riep.inep.gov.br/server/api/core/bitstreams/44bc8165-f437-4d85-88ad-14a5f3eb30b3/content) e [licença do depósito](https://riep.inep.gov.br/server/api/core/bitstreams/abbbd2e2-3374-48d3-ba42-14da7c6c877b/content).

Autoria e atribuição: Instituto Nacional de Estudos e Pesquisas Educacionais Anísio Teixeira (Inep), ENADE 2023, Medicina, caderno 18. `LICENSE.txt` preserva a licença CC BY 4.0 disponibilizada no depósito. O gold é uma transcrição estrutural de QA, conferida contra o PNG do documento original e validada independentemente pelo orquestrador; não deriva da saída do helper. Os caminhos privados registrados no gold documentam a conferência original e não são dependências do teste.
